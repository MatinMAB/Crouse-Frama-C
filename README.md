# Frama-C/Eva Analysis Workspace

This repository is for Frama-C/Eva static analysis.

- `src_original/` contains the untouched delivered code and must remain pristine.
- `src_analysis/` contains the editable analysis copy for future analysis-only changes.
- Harnesses will be added later under `harnesses/`.
- Analysis results and reports will be generated later under `results/` and `reports/`.
