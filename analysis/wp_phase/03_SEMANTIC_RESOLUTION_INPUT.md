# Semantic Resolution Input

۳۵ target از نوع `CODE_REPAIR` و ۱۳ target از نوع `SPECIFICATION_COMPLETION` هستند. پنج specification completion منشأ `REPOSITORY_INFERRED` و هشت مورد منشأ `THESIS_POLICY_SELECTED` دارند. این provenance حذف یا یکسان‌سازی نشده است.

در code repair، property ثابت است و implementation اصلاح‌شده باید آن را برقرار کند. در specification completion، constraint دامنه یا interface ثبت می‌شود و proof به همان assumption صریح محدود است. validator equality مستقیم contract با target predicate را flag می‌کند؛ rationale انسانی در repair matrix باقی می‌ماند.
