# Scope and Scientific Rules

هدف، پایش runtime برای ۱۰۱ property فاقد proof است. حذف check فقط به علت WP `VALID` مجاز است؛ هزینه، دشواری instrumentation یا زمان اجرا دلیل selection نیست.

Claimهای مجاز:

- «در execution ثبت‌شده check مشخص نقض شد.»
- «در executionهای ثبت‌شده نقض مشاهده نشد.»

Claimهای غیرمجاز:

- نبود violation معادل proof یا safety عمومی است.
- ۴۸ selected property اثبات‌شده معادل safe بودن کل تابع/برنامه است.
- runtime host-native نتیجه‌ای architecture-independent می‌دهد.

Stable identity بر پایهٔ `KLEE-ALARM-NNNN`، `eva_klee_alarm_NNNN` و canonical predicate است؛ line number به‌تنهایی identity نیست.
